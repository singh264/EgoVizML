# Data Directory

This directory contains processed prediction data and metadata files. Raw video data is **not** stored here — it lives on the lab's data storage.

---

## Pickle files

These files are large and represent cached outputs of the pipeline. They are checked into the repo to avoid re-running expensive inference steps.

| File | Size | Description | Generated by |
|---|---|---|---|
| `home_data_all_preds.pkl` | ~36 MB | Combined Detic + SHAN predictions for all videos. Dict keyed by `{adl}_{patient}_{video}`. Each entry has `remapped_metadata`, `active_objects`, and raw detection fields. | `scripts/process_all_preds.py` |
| `home_data_all_preds_df.pkl` | ~4.7 MB | Pre-converted DataFrame version of the above (rows = frames). Used as input to `generate_binary_presence_df()`. | Saved during analysis in `notebooks/` |
| `home_data_detic_preds.pkl` | ~38 MB | Post-processed Detic-only predictions (before SHAN active object step). Each entry has `remapped_metadata` and `remapped_classes`. | `scripts/process_detic.py` |
| `home_data_eval_all_preds.pkl` | ~1.9 MB | Evaluation dataset containing both Detic detections and ground truth labels per frame. Used in `notebooks/4_effect_of_detections.ipynb` to compare model performance against labelled ground truth. | Manually annotated + processed |

### Prediction dict format

```python
# home_data_all_preds.pkl — each entry:
{
    'boxes': list[list[int]],        # Bounding boxes [x1, y1, x2, y2]
    'scores': list[float],           # Detection confidence scores
    'classes': list[int],            # Original Detic class IDs
    'metadata': list[str],           # Original Detic class names
    'remapped_metadata': list[str],  # Mapped to 29 functional categories
    'remapped_classes': list[int],   # Functional category IDs
    'active_objects': list[bool],    # True if object IoU with hand box > 0.75
}
```

## JSON files

| File | Description |
|---|---|
| `dashboard_video_keys.json` | Maps patient IDs → recording dates → raw GoPro video filenames. Used by `scripts/get_dashboard_metrics.py` to look up which videos belong to each patient session. |
| `patient_adl_breakdown.json` | Manually curated per-patient ADL minute counts (hand-annotated for 5 participants). Input to `scripts/home_data_adl_breakdown.py` to generate the stacked bar chart. |
